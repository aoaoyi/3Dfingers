# ReLeaf Duo 2.0 验证记录

在 Debian 13 云机器上实际执行，2026-10-13。
参考图使用仓库原有 `preview_3D.png`；未收到其他独立的设计参考图片。

## 通过的验证

- Linux GCC 14，C++11，`-Wall -Wextra -Wpedantic -Werror` 编译及链接通过。
- Linux CMake Release 构建通过；CTest 实际执行 `geometry`，1/1 通过。
  测试使用 `-UNDEBUG`，Release 模式也执行所有断言。
- MinGW Windows x64 交叉编译及链接通过；CMake Release 项目通过。
- 直接读取 `.cbp` XML 中的 Debug 和 Release 编译/链接选项，分别使用 MinGW
  编译完整 `main.cpp`，并额外启用 `-Werror`，两者通过。不是 Code::Blocks GUI 运行结果。
- PE 检查确认 EXE 和 FreeGLUT DLL 均为 x86-64。EXE 导入仅包含 `libfreeglut.dll`
  和 Windows 系统 DLL，无需另附 `libgcc`、`libstdc++` 或 `libwinpthread` DLL。
- `--self-test --capture` 在 Xvfb / Mesa 软件 OpenGL 中实际运行并通过。
  检查键盘选择、单指指环调整、模式、模拟强度、顺序/辅助模式、范围/速度、
  三种视角、鼠标旋转/滚轮、投影选指、控制器加号、启动/暂停、急停保持、恢复、
  训练计时/计次、20 次自动暂停、新一轮启动、窗口投影尺寸及 OpenGL 错误状态。
- `--play --frames 120 --capture` 完成连续渲染，实际推进约 4.68 秒模拟时间。
- 实际生成并人工查看透视、俯视、侧视、正视和 28° 屈曲截图。
  另外生成连续动画截图及 2880×1800 高分辨率截图，并复核高分辨率布局。
- 项目自身修改的 `git diff --check` 通过。原样保留的上游 FreeGLUT 许可和部分头文件
  有尾随空白/文件末尾空行提示；不修改上游资源及其校验值。

## 几何检查

`tests/geometry_test.cpp` 直接使用应用同一份 `geometry.h`：

- 每个厚壳 3,074 顶点 / 6,144 三角形；每个内衬 2,466 顶点 / 4,928 三角形。
- 四个封闭网格检查有限坐标、单位法线、非零三角形、法线与绕序一致、
  正体积、每条边恰有两个面且方向相反。
- Bézier 内衬与壳面偏移间距检查通过。
- 五指相对长度符合用户给出的比例区间。
- 扫描 0°–32° 的 321 个屈曲角度；对指环弧面扫描 -20°–20° 的 9 个配合角。
  验证拇指与左翼的纵向间距、四指与双翼的横向间距、指环离地及掌托区域间距。
- 对整个椭圆掌托采样，验证表面高于两层底座，并保留至少 0.02 模型单位的余量。

这些是针对当前参数的保守包络检查，不是任意模型的全三角形碰撞检测。
应用限制范围为 8°–32°，指环配合角为 ±20°。改变几何、关节倍率或角度限制后应重跑测试。

## 尚未验证或仍有局限

- 未在 Windows 实机、Code::Blocks GUI 或 Intel Arc 140T 上执行程序。
  交叉编译不能证明该电脑的显卡驱动、120 Hz 表现、构建后复制命令或 Windows DPI 行为。
- 控件和指环采用屏幕投影的最近目标拾取，未实现精确遮挡/射线三角形拾取。
  在重叠视角可通过数字键选指。
- 未实现通用实时碰撞求解、接触力学或医疗控制；固定轴与壳体接合处的局部重叠
  是结构连接的视觉表示。训练、辅助与阻力全部为模拟。
- 主控屏文字是 3D 栅格文字，在低角度视角可能重叠；HUD 始终提供相同关键状态。
- 可选的加热、振动与电刺激模块没有实现。

## 资源来源

FreeGLUT 来自官方 `v3.4.0` 标签，以 TLS 下载并本地交叉构建；许可与构建说明位于
`third_party/freeglut/`。系统开发包通过带签名元数据和包哈希的 Debian 仓库下载，
解包至仓库之外的 `/workspace/releaf-tools`，没有修改系统目录。
