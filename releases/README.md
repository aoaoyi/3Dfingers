# Windows x64 download

Download `ReLeaf_Duo-2.0-windows-x64.zip` using GitHub's **Download raw file**
button on the ZIP file page, or use the direct link:

https://github.com/aoaoyi/3Dfingers/raw/refs/heads/codex/releaf-duo-2.0/releases/ReLeaf_Duo-2.0-windows-x64.zip

Extract the archive and launch `ReLeaf_Duo/bin/Release/ReLeaf_Duo.exe`.
Keep `libfreeglut.dll` beside the executable. The archive also contains all source
files, the Code::Blocks project, CMake configuration, tests and screenshots.

The executable was cross-compiled for Windows x64 with MinGW; Windows hardware
and Code::Blocks GUI execution have not been tested. See `docs/validation.md`.

The adjacent `.sha256` file records the SHA-256 checksum of the ZIP.
